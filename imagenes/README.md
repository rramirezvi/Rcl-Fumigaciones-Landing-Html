# Imagenes del hero

Coloca aqui las imagenes que apareceran en el carrusel del cuadro principal.

Usa estos nombres exactos:

- `hero-1.jpg`
- `hero-2.jpg`
- `hero-3.jpg`

Dimensiones recomendadas:

- Ideal: `1600 x 1000 px`
- Tambien funciona bien: `1200 x 800 px`
- Minimo recomendado: `900 x 600 px`

La pagina usa `background-size: cover`, asi que el CSS se encarga de adaptar la imagen al cuadro. Conviene usar fotos horizontales para evitar recortes fuertes.
